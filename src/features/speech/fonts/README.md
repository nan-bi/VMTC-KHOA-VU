# Font giao diện Vú Voice

Noto Sans variable, hỗ trợ tiếng Việt; bản gốc có hai trục wdth/wght. Tên file trong dự án được đặt lại để nhận diện mục đích sử dụng, không thay đổi dữ liệu font.

Nguồn: https://github.com/google/fonts/tree/main/ofl/notosans

Tệp gốc: `NotoSans[wdth,wght].ttf`.

Giấy phép SIL Open Font License 1.1 được giữ tại `OFL.txt`. Font được đóng gói cùng bản build và cache ngoại tuyến; không gọi Google Fonts khi người dùng mở giao diện.
